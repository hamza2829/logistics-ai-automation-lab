# 30-minute colleague session

**Outcome.** Each colleague can draft a narrow AI task, inspect one mistake, and explain when to involve a human. Use the lab's fictional requests. A facilitator can use the checked-in benchmark report and workflow log for the entire session.

| Time | Activity |
| --- | --- |
| 0 to 5 min | Pick a service request. Describe the decision a colleague makes and which steps must stay under staff control. |
| 5 to 10 min | Read the process chart. Identify the slowest simulated step and discuss what evidence would distinguish waiting from hands-on work. |
| 10 to 18 min | In pairs, draft an instruction that requests a category, evidence from the request and a review flag. Try a straightforward example and a mixed-intent example. Use the benchmark results as the demo if an approved tool is unavailable. |
| 18 to 25 min | Compare with the expected labels. Find one confident error and one review case. Walk through the approval and rejection outcomes in the run log. |
| 25 to 30 min | Share one metric, one stop condition, and one person who should own the decision. |

**Exercise text.** “The warehouse order is already staged. Decide which van should collect it.” Ask whether the work is dispatch or a warehouse order, and point to the action being requested.

**Prompt pattern.** “Classify this fictional request into mail and parcel, dispatch, driver bookings, warehouse orders or other. Identify the words that support your choice. Mark for review if multiple routes are plausible.”

**Exit check.** Name a confident but incorrect result and explain which human check would catch it. Keep internal messages, names, addresses and shipment references out of unapproved tools.
